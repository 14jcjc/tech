## katsuについて

上智大学および同大学院で数学を専攻。

データサイエンティスト／SEとして20年以上、データサイエンス分野を中心に、データ分析やシステムの設計・開発などに携わってきました。  
懸賞金付きデータサイエンス・コンテストでは、2度の準優勝を果たしています。

分析や推論そのものに昔から強い関心があり、現在はデータサイエンスに関する情報発信を行いながら、いくつかの個人プロジェクトに取り組んでいます。

### 水平思考クイズの制作

論理パズルや水平思考クイズも、長く親しんできたテーマのひとつです。

これまでに解いたウミガメのスープは1,000問以上。  
水平思考クイズの制作をライフワークとし、論理設計の経験を活かして、納得感を重視した問題を数多く考案しています。

制作した問題を通話アプリで多くの人に出題し、好評を得ています。  
寄せられた反応や意見をもとに、問題文やヒント、難易度を調整しています。

著書に『謎解き水平思考クイズ VOL.1: 多段階ヒント付き ウミガメのスープ』（Kindle）があります。

2025年よりJAPAN MENSA会員。  
同会の月刊会報誌のクイズコーナーに、自作のクイズがこれまでに3回掲載されています。

こうした活動を通じて、思考の前提を見直す面白さを、より多くの人に届けたいと考えています。

データ分析とクイズ制作に共通しているのは、結果や答えだけでなく、そこに至るまでの考え方や読み解きの過程にも面白さがあることです。

## 当サイトについて

当サイトでは、R と SQL を中心としたデータサイエンスの実践情報と、水平思考クイズや論理パズルなど、考えることを楽しむためのコンテンツを発信しています。

データサイエンスの記事では、基礎的な内容から、実務で使いやすい考え方や手順まで、できるだけ順を追って整理することを意識しています。

特に演習問題の記事は、手を動かしながら理解を深められるように構成しています。
